# 공개·배포 전 확인

Petmily의 공개 코드를 로컬에서 실행하려면 개발용 MariaDB와 외부 설정이 필요하다. [로컬 실행](../LOCAL_DEVELOPMENT.md)

기능 검사는 격리 환경에서 수행했다. 운영 스키마, 배포 HTTPS, 외부 연동과 동시 요청의 확인 범위는 [테스트 문서](../TESTING.md#남은-검증)에 정리했다.

## 배포 설정

- 과거 Git 이력의 DB·JWT·AWS 설정은 실제 사용 여부와 폐기·교체 상태를 확인해야 한다. 현재 설정을 외부 파일로 옮겨도 과거 커밋의 내용은 남는다.
- Kakao 지도 JavaScript 키의 등록 도메인과 허용 범위는 콘솔에서 확인해야 한다.
- 개발용 SMTP 더미와 실제 메일 서비스 설정은 구분한다. 개발 환경은 저장소 밖 설정 파일을 사용한다.
