# 공개·배포 전 확인

Petmily를 로컬에서 실행하려면 개발용 MariaDB와 외부 설정이 필요합니다. [로컬 실행](../LOCAL_DEVELOPMENT.md)

기능 테스트는 격리 환경에서 진행했습니다. 운영 DB 스키마, HTTPS, 외부 연동과 동시 요청 등 추가 확인이 필요한 항목은 [테스트 문서](../TESTING.md#남은-검증)에 정리했습니다.

## 배포 설정

- 과거 Git 이력에 포함된 DB·JWT·AWS 설정의 실제 사용 여부와 폐기·교체 여부를 확인해야 합니다. 현재 설정을 외부 파일로 옮겨도 과거 커밋에는 남아 있습니다.
- Kakao 지도 JavaScript 키의 등록 도메인과 허용 범위를 콘솔에서 확인해야 합니다.
- 개발용 SMTP 더미와 실제 메일 서비스 설정은 구분합니다. 개발 환경에서는 저장소 외부의 설정 파일을 사용합니다.
